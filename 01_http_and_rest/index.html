    Частина I. HTTP і дизайн REST API¶

    Що таке API і які вони бувають (REST, gRPC, GraphQL, WebSocket), принципи REST, коди відповідей, версіонування. Приклад — API метеостанцій examples/meteo_api, бо на ньому видно дизайн API ще до FastAPI-специфіки.

    Розділи¶

    Розділ Код Стан
    HTTP-запит і відповідь зсередини examples/http_anatomy/inspect_app.py, raw_client.py готово
    Методи HTTP: безпечність, ідемпотентність, кеш examples/http_anatomy/methods_app.py готово
    Коди відповідей examples/http_anatomy/codes_app.py готово
    Принципи REST examples/http_anatomy/cache_app.py, cache_demo.py готово
    Колекції: адреси, фільтри, сортування, пагінація examples/pagination/pagination_app.py, pagination_demo.py готово
    Версіонування API examples/versioning/versioning_app.py, versioning_demo.py готово
    Формат помилок: RFC 9457 examples/errors/problem_app.py, naive_app.py готово
    Які бувають API examples/meteo_api/api_styles_demo.py, examples/realtime/realtime_app.py готово
    HTTP-клієнти: requests, httpx, aiohttp examples/http_clients/ готово
    Кейс: API v1 → v2 meteo_api/legacy/ готово
    Архітектура: API, клієнт і карта examples/meteo_api готово
