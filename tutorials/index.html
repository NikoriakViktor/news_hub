    Крок Що додається Тестів
    0. Що таке API клієнт і сервер, перший API на 13 рядків, перевірка знань —
    1. Типи і Pydantic анотації типів, NewsItem, validate_news 12
    2. Перший API на FastAPI GET /api/news, POST /api/scrape, Depends, /docs, Postman 23
    3. SQLAlchemy і Alembic база, репозиторій, CRUD, міграції 32
    4. Middleware, кеш і Redis middleware, кеш, rate limit, фоновий збір 41
    5. Тестування API unit / integration, фікстури, моки, фейки, покриття 86
    6. AI-інструменти Claude Code, RSS-джерело, написане AI за тестами 107
    7. LLM API аналіз новин Gemini / Anthropic, circuit breaker 168
    8. Безпека JWT адміна, SSRF, підписані webhook 279
    9. Telegram-бот aiogram, підписки, polling і webhook 335
    10. Docker образ, HEALTHCHECK, /health/ready 340
    11. Compose і деплой nginx, PostgreSQL, Redis, міграції, бекап 343
    12. CI/CD GitHub Actions, mypy, smoke, ghcr.io 343

    «Тестів» — скільки проходить pytest -q у папці кроку (без тестів, що потребують Docker або справжнього LLM).

    Ніколи не писав API? Почни з кроку 0: там пояснено простими словами, що таке клієнт, сервер і API, ти запустиш перший сервер на 13 рядків і перевіриш себе перед кроком 1. Перед стартом — Налаштування.
