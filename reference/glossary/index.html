    Глосарій¶

    Терміни книги: коротке означення і де розібрано. Латинські — за абеткою, далі українські. Терміни Django — у глосарії Django-книги.

    A–Z¶

    Термін Що це Де
    Alembic міграції схеми для SQLAlchemy: revision --autogenerate, upgrade head, check крок 3
    Annotated Annotated[T, метадані]: тип першим, далі Query(...), Depends(...), Field(...) Анотації типів
    API Gateway точка входу перед кількома сервісами: TLS, маршрутизація, ліміти Архітектура
    APIRouter група маршрутів зі спільним префіксом, тегами й залежностями Шпаргалка FastAPI
    ASGI інтерфейс між async-сервером (uvicorn) і застосунком (FastAPI): HTTP, WebSocket, lifespan Архітектура
    BackgroundTasks функції, які FastAPI виконує в тому самому процесі після відправлення відповіді крок 4
    bcrypt повільний хеш пароля з сіллю і кількістю раундів ($2b$12$…) крок 8
    BFF Backend for Frontend: сервіс, що збирає дані кількох сервісів для одного клієнта Архітектура
    cache-aside спершу кеш; немає — база, і результат кладемо в кеш крок 4
    CI/CD автоматична перевірка кожної зміни (CI) і публікація результату (CD) крок 12
    circuit breaker після N збоїв поспіль перестає кликати провайдера на час T і одразу відповідає 503 крок 7
    CORS правила браузера, яким сайтам дозволено читати відповіді API; сервер дозволяє заголовками Access-Control-* CORS
    Depends оголошення залежності: FastAPI викликає функцію й передає результат в ендпоінт Залежності
    DI Dependency Injection: код отримує ресурси ззовні, а не створює сам — тому їх легко підмінити в тестах Залежності
    dependency_overrides словник «залежність → підміна» для тестів Шпаргалка FastAPI
    event loop цикл подій: один потік перемикає корутини, поки вони чекають I/O Архітектура
    exclude_unset model_dump(exclude_unset=True) — лише поля, які клієнт передав; основа PATCH Моделі Pydantic
    fakeredis Redis у пам'яті процесу для тестів; REDIS_URL=fakeredis:// крок 4
    FakeLLM клієнт LLM без мережі з передбачуваними відповідями; LLM_PROVIDER=fake крок 7
    flush надіслати SQL у базу зараз (отримати id, помилки обмежень), COMMIT — пізніше крок 3
    from_attributes Pydantic будує модель з атрибутів об'єкта (рядка SQLAlchemy) ConfigDict
    healthcheck команда, якою Docker перевіряє контейнер; у News Hub — /health (образ) і /health/ready (Compose) крок 10
    HMAC підпис повідомлення спільним секретом: sha256=<hex> від часу й тіла крок 8
    IDOR доступ до чужого об'єкта підстановкою його id; захист — шукати серед своїх, чужий → 404 Колекції
    idempotency повтор запиту дає той самий стан, що й один запит: GET, PUT, DELETE — так, POST — ні Методи HTTP
    Idempotency-Key заголовок, за яким сервер розпізнає повтор того самого POST Методи HTTP
    JSON Schema опис структури JSON; Pydantic генерує її для OpenAPI і для відповіді LLM крок 7
    JWT підписаний токен заголовок.дані.підпис; News Hub перевіряє exp, sub, role крок 8
    lax / strict режими Pydantic: перетворювати "5" на 5 чи ні lax і strict
    lifespan код запуску й зупинки застосунку: до yield і після Залежності
    liveness / readiness «процес живий» (/health) і «готовий обслуговувати: база й Redis доступні» (/health/ready) крок 10
    LLM велика мовна модель; у News Hub — Gemini або Anthropic за інтерфейсом LLMClient крок 7
    mass assignment клієнт задає поля, яких не мав би (is_admin), бо тіло копіюється в модель цілком ConfigDict
    middleware код навколо кожного запиту: бачить запит до ендпоінта і відповідь після крок 4
    MissingGreenlet помилка SQLAlchemy async: лінивий зв'язок завантажується поза await ConfigDict
    mock / fake мок підміняє виклик і перевіряє, як його викликали; фейк — робоча спрощена реалізація крок 5
    OpenAPI машинний опис API (/openapi.json), з якого будуються /docs і клієнти OpenAPI
    PID 1 перший процес контейнера; саме він отримує SIGTERM від docker stop крок 10
    polling / webhook (Telegram) бот сам питає getUpdates / Telegram надсилає update на HTTPS-адресу крок 9
    preflight запит OPTIONS, яким браузер питає дозволу CORS перед «непростим» запитом CORS
    prompt injection текст з даних (новини), що намагається керувати моделлю як інструкція крок 7
    Protocol інтерфейс для mypy за структурою: «має методи X» без спільного базового класу Анотації типів
    Pydantic бібліотека перевірки й серіалізації даних за анотаціями типів Частина II
    rate limit обмеження кількості запитів за вікно часу; перевищення — 429 + Retry-After крок 4
    replay повторне надсилання перехопленого підписаного запиту; захист — час у підписі й журнал підписів крок 8
    Repository клас, у якому живуть усі запити до однієї таблиці; ендпоінт кличе його методи крок 3
    response_model модель, через яку FastAPI пропускає відповідь: зайві поля відкидаються Маршрути
    REST стиль API: ресурси за адресами, стандартні методи й коди, без стану між запитами Принципи REST
    scope="function" код після yield залежності виконується до відправлення відповіді Залежності
    SecretStr рядок, що друкується як **********; значення — get_secret_value() Налаштування
    smoke-тест короткий прогін головного шляху на справжньому стеку: «чи взагалі працює» крок 12
    SSE Server-Sent Events: потік подій від сервера в одній HTTP-відповіді Стилі API
    SSRF сервер на прохання клієнта звертається туди, куди не мав би: localhost, внутрішня мережа, метадані хмари крок 8
    Starlette ASGI-інструментарій, на якому побудовано FastAPI Що таке FastAPI
    TestClient клієнт HTTPX, що викликає застосунок без мережі; з with — запускає lifespan Шпаргалка FastAPI
    threadpool пул потоків (40), де FastAPI виконує def-ендпоінти й синхронні залежності Архітектура
    TTL час життя ключа в Redis; після нього ключ зникає сам крок 4
    TypedDict словник з відомими ключами й типами — для mypy і Pydantic крок 1
    Unit of Work усі зміни однієї операції — в одній транзакції: COMMIT разом або ROLLBACK разом Архітектура
    uvicorn ASGI-сервер, що запускає News Hub Команди
    WSGI синхронний інтерфейс сервер ↔ застосунок (Django без async, Flask) Архітектура
    WebSocket двобічне з'єднання поверх HTTP для повідомлень в обидва боки Стилі API
    X-Forwarded-For заголовок проксі з IP клієнта; вірити — лише своєму nginx (FORWARDED_ALLOW_IPS) крок 11

    міграція версійований скрипт зміни схеми бази крок 3
