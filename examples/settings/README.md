# Налаштування: pydantic-settings

```bash
pip install -r requirements.txt
python settings_demo.py   # пріоритет джерел, extra і чужі ключі в .env, SecretStr, помилки при старті, $ у .env
```

Демо створює тимчасову папку з `.env` і `secrets/`, тож нічого у твоїй системі не змінює.
Розбір — сторінка книги «Налаштування: `pydantic-settings`, `.env`, `SecretStr`» (Частина II).
