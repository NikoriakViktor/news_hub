# Legacy: Meteo Telegram API (v1)

Перша версія API — для розбору «як було». **Не запускається в прикладі** (потрібні MongoDB і доступ до ogimet.com).

- `main.py` — FastAPI + MongoDB, з проєкту `ogimet-main/meteo_telegram/main.py`
  (перша версія — репозиторій [`NikoriakViktor/ogimet`](https://github.com/NikoriakViktor/ogimet), 2024).
- `streamlit_app.py` — Streamlit-клієнт до цього API з того самого проєкту.

REST-версія того самого API — `../app.py`.
