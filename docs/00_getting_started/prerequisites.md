# Необхідні знання

Не впевнений, чи вистачає знань? Пройди [перевірку з відповідями](../tutorials/00_first_api/readiness.md): 14 питань за темами нижче, а для кожної теми — де підтягнути.

## Потрібно

| Тема | Навіщо | Достатній рівень |
|---|---|---|
| Python | весь код | функції, класи, винятки, модулі й пакети, `with`, генератори списків |
| Термінал | запуск, тести, Docker | `cd`, `ls`/`dir`, змінні середовища, запуск скрипта |
| Git | кроки, порівняння, CI | `clone`, `status`, `diff`, `commit`, гілки |
| venv і pip | залежності кожного кроку | створити й активувати середовище, `pip install -r` |
| HTTP | API | метод, URL, заголовки, тіло, код відповіді — [Частина I](../01_http_and_rest/README.md) пояснює решту |
| SQL | крок 3 і далі | `SELECT`, `INSERT`, `WHERE`, первинний і унікальний ключ |

## Корисно, але не обов'язково

- **Django і DRF** — тоді [«FastAPI і DRF»](../03_fastapi_core/README.md) покаже, що те саме робиться інакше.
- **`asyncio`** — `async def`, `await`, `asyncio.gather`; [Частина IV](../04_async/README.md) пояснює з нуля.
- **Docker** — потрібен з кроку 10; для кроків 3–4 зручний, щоб підняти PostgreSQL і Redis.

## Версії

| Що | Версія |
|---|---|
| Python | 3.10+ (CI фінального кроку — 3.10 і 3.13) |
| FastAPI, Pydantic, SQLAlchemy… | нижні межі — у `requirements.txt` кроку; CI фінального кроку перевіряє саме їх |
| Docker | Docker Desktop або Docker Engine з плагіном Compose v2 (`docker compose`) |
