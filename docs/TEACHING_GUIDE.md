## Як проводити крок

1. **Де ми зараз** — відкрити попередній крок, запустити тести, показати `/docs`.
2. **Проблема** — що не працює або що болить без нового коду.
3. **Зміна** — `git diff --no-index` між кроками на екрані, файл за файлом.
4. **Результат** — тести кроку, запит у `/docs` або Postman.
5. **Правило** — що з цього варто забрати в будь-який проєкт.
